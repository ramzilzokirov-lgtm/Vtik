# TT Mod / Vtik

An independent Android customization project inspired by short-video apps. This repository is the new home for the TikTok-style mod; the older VGRAM/Telegram work is not part of this project.

## Direction
- Dark AMOLED-first interface with muted yellow accent.
- Material 3-inspired controls, optional Liquid Glass styling, adjustable accent color.
- Short-video feed concept with swipe/scroll navigation and configurable interface elements.
- Playback speed, seek controls, auto-scroll, filters, comment translation hooks, and media saving where permitted by the platform and applicable rights.
- Anti-burn-in option and reminders for streak/“огонёк” maintenance.
- Profile badges: TESTER, OG/OLD, FRIENDS, TEAM; only the project owner/admin can award them.
- Settings for themes, interests, background, and hidden UI elements.
- Developer and updates screens.

## Current status
This repository currently starts with a mobile web UI prototype, not a working APK. Real TikTok account login, feed access, comments, and downloads require a compatible and permitted integration; the prototype does not pretend to connect to TikTok. Do not put private tokens or account credentials in source control.

## Roadmap
1. Build and review the mobile interface prototype.
2. Choose an Android implementation path and add a reproducible GitHub Actions build.
3. Add features in small, testable steps.
4. Validate app permissions, platform rules, and media rights before adding account or download integrations.
