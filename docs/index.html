Документация vTOK

Справочник по интерфейсу, плагинам и публикации версий. Проект находится в разработке.

Статус

Что работает сейчас

  • Интерактивный демонстрационный интерфейс и нижняя навигация.
  • Локальный выбор цвета акцента, эффекта стекла и параметров макета.
  • Страницы документации и магазина обновлений как отдельные веб-модули.

Авторизация TikTok, реальные видео, синхронизация огонька и APK пока не подключены.

Архитектура плагинов

Планируемая модель: плагины — отдельные пакеты с манифестом, версией API, списком разрешений и точкой входа. Каждый плагин должен быть подписан и проверен перед установкой. Не запускайте неизвестный код и не храните секреты внутри плагина.

{
  "id": "example.plugin",
  "name": "Example",
  "version": "1.0.0",
  "apiVersion": 1,
  "permissions": ["settings.read"],
  "entry": "plugin.js"
}

Это пример схемы для будущего менеджера, а не готовый исполняемый формат. Неизвестные разрешения должны отклоняться; сетевые и медиа-разрешения — запрашиваться отдельно.

Настройки

  • Акцент: цвет кнопок и активных элементов.
  • Эффект стекла: прозрачная размытая нижняя панель (при выключении будет непрозрачной).
  • Anti-burn-in: сдвиг отдельных элементов — в прототипе ограниченная имитация.
  • Автопрокрутка: переход к следующему демонстрационному экрану.

Публикация обновления

  1. Собрать и проверить APK.
  2. Открыть отдельный vTOK Store.
  3. Выбрать APK, указать версию и описание.
  4. Публиковать через защищённый backend/GitHub Release endpoint.

Важно: веб-страница сама по себе не может безопасно выпускать релизы в GitHub без серверной авторизации. Токен нельзя помещать в HTML или публичный репозиторий.

Скачивание видео

Сохранение без водяного знака допустимо только для контента, который пользователь вправе сохранять, и при соблюдении правил платформы и прав автора. В прототипе реального загрузчика нет.
