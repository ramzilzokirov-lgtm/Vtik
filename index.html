Документация

Что это за проект

vTOK — проект Android-приложения. Сайт служит страницей публикации версий, документации и информации о бейджах.

Установка APK

  1. Скачай APK из опубликованного релиза.
  2. Открой файл на Android и разреши установку из этого источника, если система попросит.
  3. Если установка не подходит к устройству, проверь требования версии в описании релиза.

Документация для пользователей

  • Скачивай приложение только из официального релиза проекта.
  • Перед обновлением проверь список изменений и совместимость.
  • Если установка завершилась ошибкой, сообщи версию Android и номер релиза в разделе Issues.

Документация для владельца проекта

Публикуй APK как вложение к GitHub Release. Не добавляй пароли, токены или личные данные в публичные файлы. Бейджи в этом каталоге пока демонстрационные; реальные продажи требуют настроенного платёжного провайдера, правил возврата и защищённого механизма выдачи.

Как публикуются обновления

В GitHub репозитории открой Releases → Create a new release, укажи тег версии, добавь описание изменений и прикрепи APK в разделе файлов релиза. После публикации сайт автоматически покажет версию и ссылку на APK.

Документация по плагинам

Раздел описывает планируемую систему расширений vTOK. Совместимость плагинов пока не гарантируется: загружай только файлы, которым доверяешь.

Что может делать плагин

  • Добавлять необязательные настройки интерфейса и темы.
  • Менять визуальные элементы только через разрешённые API приложения.
  • Подключать дополнительные функции, если соответствующий API будет реализован.

Как подготовить плагин

  1. Проверь версию vTOK и версию API, для которой предназначено расширение.
  2. Подготовь исходный код, описание функций, автора, лицензию и список разрешений.
  3. Не запрашивай пароли, коды входа, токены или доступ к личным сообщениям без реальной необходимости.
  4. Проверь расширение на тестовом устройстве и опиши известные ограничения.
  5. Публикуй исходники и инструкции в отдельном репозитории GitHub; укажи контрольную сумму релизного файла.

Безопасность и совместимость

Не устанавливай неизвестные APK или библиотеки. Не отключай защиту Android ради плагина. Подпись, формат пакета, разрешения, API и механизм установки плагинов ещё должны быть реализованы в приложении; этот сайт сам по себе не устанавливает и не запускает плагины.
