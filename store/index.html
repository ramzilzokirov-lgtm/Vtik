Публикация обновления

Отдельная панель управления обновлениями. Выбери APK, введи версию и описание — форма подготовит пакет релиза.

Файл остаётся в этом браузере; пока не отправляется на сервер.

Подключение публикации в один клик

Чтобы реально выпускать обновления одной кнопкой, нужна защищённая серверная функция, которая создаёт GitHub Release и прикрепляет APK. Встраивать GitHub-токен в эту страницу нельзя: его сможет украсть любой посетитель.

Целевой workflow: выбрать APK → проверить версию → нажать «Опубликовать» → backend проверяет доступ → создаёт релиз и возвращает ссылку на скачивание.

Сейчас это интерфейс подготовки, а не фактическая публикация. Платные сервисы не создавались.
