В ПЛАНАХ

Как это работает

  1. 1Выбери проверенный APK и укажи номер версии.
  2. 2Добавь список изменений и выбери канал релиза.
  3. 3Подготовь метаданные и проверь их перед публикацией.
  4. 4Для публикации одним нажатием подключается защищённый релизный API.

Безопасность: секреты GitHub нельзя хранить в клиентском HTML. Для реальной публикации потребуется защищённый backend или GitHub Actions workflow с авторизацией владельца.
